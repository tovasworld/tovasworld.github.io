Privacy Policy

Last updated: 27 September 2026

Who we are

Tova's World is an independent YouTube channel for young children. This policy covers this website and "Tova Uploader", a private tool the channel owner uses to publish videos to the Tova's World YouTube channel.

This website

This website does not use cookies, analytics, advertising or tracking of any kind, and it does not collect any personal information from visitors. It is hosted on GitHub Pages; GitHub may keep standard server logs under its own privacy policy.

Children's privacy

Our videos are made for children. We never ask children for personal information. Videos are published on YouTube as "made for kids", which turns off personalised ads and comments under YouTube's rules.

Tova Uploader uses YouTube API Services

Tova Uploader uses YouTube API Services only to upload videos to, and manage videos, thumbnails and playlists on, the channel owner's own YouTube channel. It is used only by the channel owner. It does not access, collect, store or share data about any other YouTube user or viewer.

The authorisation token that allows the tool to upload is stored only on the channel owner's own computer and is never shared with anyone. You can see how Google handles data in the Google Privacy Policy. Use of YouTube is subject to the YouTube Terms of Service. Access can be revoked at any time on the Google security settings page.

Data retention and deletion

Tova Uploader does not store any data obtained from YouTube API Services other than the video IDs of the channel owner's own uploads, which are kept in local project notes. No data about other users is ever collected, so there is nothing to delete for anyone else. The channel owner can delete the stored authorisation token at any time, and access is also removed immediately when it is revoked on the Google security settings page. Any stored data is deleted within 30 days after it is no longer needed.
